WristCommand Own 준비WristCommand Own setup

WristCommand Own은 본인 개발자 계정의 무료 사용량으로 인터넷(폰 경유) 명령을 쓰는 앱입니다. 처음 한 번 약 30분 준비가 필요하고(개발자 앱 승인 대기는 빼고), 폰만으로 할 수 있으며, 개발자 사이트와 GitHub 화면은 영어입니다.

WristCommand Own uses your own developer account's free usage for remote (phone) commands. The one-time setup takes about 30 minutes plus the wait for developer app approval, and can be done on a phone.

이 페이지는 인터넷으로 아무것도 보내지 않습니다. 입력한 값은 이 화면과 클립보드에만 있습니다. 개발자 계정에 결제수단은 넣지 마세요 — 이 앱은 무료 사용량 안에서만 쓰도록 만들었고, 무료 사용량을 다 쓰면 그달 남은 기간은 블루투스로만 씁니다.

This page sends nothing over the internet. What you type stays on this screen and in your clipboard. Do not add a payment method to the developer account; the app is built to stay within the free usage, and once that runs out it uses Bluetooth for the rest of the month.

1. 차 계정 2단계 인증 켜기1. Turn on two-factor authentication on your car account

개발자 가입 조건입니다(이메일 인증 + 2단계 인증). 이미 켜져 있으면 넘어가세요.

The developer program requires a verified email and multi-factor authentication. Skip if already on.

2. 내 웹 주소 만들기 (GitHub, 무료)2. Make your web address (GitHub, free)

  1. GitHub 계정이 이미 있으면 그 계정을 쓰세요(무료 계정은 한 사람에 하나). 없으면 github.com에서 만듭니다. 아이디에 차 제조사 이름(영문)을 넣지 마세요 — 그런 주소는 등록되지 않습니다.
  2. Use your existing GitHub account if you have one (one free account per person); otherwise sign up at github.com. Do not put the car maker's name in your username; such addresses are not accepted.

  1. GitHub에서 New repository → 이름을 정확히 아이디.github.io → Public → Create repository. (이 이름의 저장소가 이미 있으면 그 저장소를 씁니다.)
  2. On GitHub: New repository → name it exactly username.github.io → Public → Create repository. (If it already exists, use it.)
  3. 아래 [공개키 파일 만들기]를 누르세요.
  4. Tap [Make public key file] below.

비밀 키는 이 브라우저 안에서만 잠깐 생겼다가 페이지를 닫으면 사라지고, 꺼낼 수도 없습니다. 시계는 이 키를 쓰지 않습니다(명령은 시계 키로 서명합니다). 주소마다 다른 키가 필요해서 만드는 것입니다.

The private half exists only inside this browser, cannot be exported, and is gone when you close the page. The watch never uses it (commands are signed with the watch key); every address just needs its own key.

  1. 저장소에서 Add file → Create new file → 파일 이름 칸에 .well-known/appspecific/com.tesla.3p.public-key.pem 붙여넣기 → 내용 칸에 위 공개키 붙여넣기 → Commit changes.
  2. In the repository: Add file → Create new file → paste .well-known/appspecific/com.tesla.3p.public-key.pem as the file name → paste the key above as the content → Commit changes.
  3. 한 번 더 Create new file → 이름 .nojekyll → 내용은 비워 두고 Commit changes. (점으로 시작하는 폴더를 웹에 보이게 하는 파일입니다.) 이미 이 저장소로 블로그 같은 사이트를 쓰고 있다면 .nojekyll 대신 _config.yml 에 include: [".well-known"] 한 줄을 더하세요 — .nojekyll 을 넣으면 그 사이트가 꺼질 수 있습니다.
  4. Once more Create new file → name .nojekyll → leave it empty → Commit changes. (It lets the dot-folder be served.) If this repository already hosts a site (e.g. a blog), add the line include: [".well-known"] to _config.yml instead; .nojekyll could switch that site off.
  5. 1-3분 뒤 내 공개키 주소를 열어 「BEGIN PUBLIC KEY」 글자가 보이면 됩니다.
  6. After 1-3 minutes open your key address; you should see “BEGIN PUBLIC KEY”.

3. 개발자 앱 만들기3. Create a developer app

차 제조사 개발자 사이트(developer.tesla.com)에 차 계정으로 로그인 → 앱 만들기. 본인 정보(이름 등)는 직접 쓰고, 아래 값은 복사해 넣으세요.

Sign in at the car maker's developer site (developer.tesla.com) with your car account → create an application. Type your own details (name etc.); copy the values below.

앱 이름Application name
설명·용도Description / purpose
OAuth Grant Type Authorization Code and Machine-to-Machine
Allowed Origin URL(s) https://아이디.github.io/
Allowed Redirect URI(s) http://localhost:8080/callback
Scopes Vehicle Information Vehicle Commands Vehicle Charging Management
  • 위 세 권한만 고르세요(위치 권한은 필요 없습니다). 앱 이름에 차 제조사 이름을 넣지 마세요.
  • Pick only those three scopes (no location needed). Do not put the car maker's name in the app name.
  • 결제(Billing) 단계는 건너뛰세요. 승인 메일을 기다립니다(몇 분에서 몇 시간 걸릴 수 있습니다).
  • Skip the billing step. Wait for the approval email (minutes to a few hours).
  • 승인되면 앱 화면에서 Client ID와 Client Secret을 봅니다.
  • Once approved, open the app to see its Client ID and Client Secret.

5. 시계로 보내기5. Send to the watch

  1. 시계에서 WristCommand Own을 열고 내 개발자 계정을 누릅니다(차가 없으면 첫 화면, 있으면 「설정·더보기」 안). 개인정보 동의 뒤 폰 알림을 누릅니다.
  2. On the watch open WristCommand Own and select My developer account (first screen if no car yet, otherwise in Settings & more). After the personal-data consent, tap the phone notification.
  3. 열린 화면 칸에 붙여넣기 → [시계로 보내기]. 시계가 주소를 등록합니다(몇 초).
  4. Paste into the box that opens → [Send to watch]. The watch registers your address (a few seconds).
  5. 곧 오는 두 번째 알림 → 차 계정으로 로그인 → 권한을 전부 허용 → 시계에 차 이름이 뜨면 끝입니다.
  6. Tap the second notification → sign in with your car account → allow all permissions → done when your car name appears on the watch.
  7. 끝나면 [클립보드 비우기]를 누르세요(한 줄에 Client Secret이 들어 있습니다). 키보드의 클립보드 기록이나 다른 기기와 공유되는 클립보드를 쓰신다면 그쪽 기록도 지워 주세요.
  8. Afterwards tap [Clear clipboard]; the line contains your Client Secret. If your keyboard keeps a clipboard history or your clipboard syncs to other devices, clear those too.

블루투스 키(차 옆에서 쓰는 시계 키)는 따로 키카드로 등록합니다. 인터넷 명령도 이 시계 키로 서명하므로 키 등록이 필요합니다. 값을 지우려면 시계의 「내 개발자 계정 지우기」를 누르세요.

The watch key is still registered separately with your key card; remote commands are signed with it too. To delete the values, use “Remove my developer account” on the watch.
